# Projet 6 : Classification de produits par le texte et l'image

Ce projet présente une analyse des caractéristiques (features) d'articles de e-commerce à partir de leurs images et de leurs descriptions textuelles. Il inclut des classifications réalisées à l'aide de modèles de Deep Learning et d'algorithmes de Traitement du Langage Naturel (NLP) et de Computer Vision.

## Description

L'objectif est d'automatiser l'attribution des catégories des articles en utilisant leurs images et leurs descriptions textuelles. Le projet met en œuvre des approches de feature extraction, de NLP (Word2Vec, BERT, etc.) et de Computer Vision (CNN, Transfer Learning) pour classer efficacement les produits.

## Contenu du dépôt

- `Mes_notebooks/` : Dossier contenant les notebooks d'analyse, d'extraction de features textuelles et visuelles, ainsi que les modèles de Deep Learning.
- `api_script.py` : Script Python pour requêter des données ou déployer un modèle via API.
- `produits_champagne.csv` : Jeu de données échantillon contenant des produits.
- `requirements.txt` : Fichier des dépendances nécessaires.

## Installation

```bash
git clone https://github.com/KamelBenstaali/OpenClassroomP6.git
```
